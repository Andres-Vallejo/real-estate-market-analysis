# Metric Dictionary

## price_usd
Listing asking price in USD.

## price_per_sqm
price_usd divided by size_sqm. Used to compare properties of different sizes.

## days_on_market
Number of days since the listing became available. Lower values usually indicate higher liquidity.

## liquidity_segment
Fast, normal, or slow listing movement based on days_on_market thresholds.

## pricing_gap_pct
Difference between asking price and model-predicted price. Positive values suggest potential overpricing; negative values suggest potential undervaluation.

## transit_score
Synthetic accessibility score from 0 to 100. Higher values indicate stronger transit access.

## condition_score
Synthetic property condition score from 1 to 5.
